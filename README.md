# Подпискомат

Черновик сайта podpiskomat.com: независимый продавец подписки Яндекс Плюс в Казахстане.

- `yandex-plus-dlya-alisy/` — страница «Подписка Алиса для колонки в Казахстане».
- `index.html` — временная главная.
- `assets/` — стили, иконка вкладки, картинки (иллюстрации и иконки сгенерированы через Codex).

Все страницы закрыты от индексации (`noindex`), пока в текстах есть плейсхолдеры `[ЦЕНА]`, `[N]` и т. п. и не подключён домен.
