# Подпискомат

Черновик сайта podpiskomat.com: независимый продавец подписки Яндекс Плюс в Казахстане и ссылок-приглашений для других стран.

Сайт статический и собирается генератором (исходники вне этого репозитория: `tools/sitegen/`). Все цены и правила хранятся в одном файле фактов (`ssot.py`) и подставляются на все страницы.

## Страницы

| URL | Задача |
|---|---|
| `/` | Купить Яндекс Плюс в Казахстане |
| `/yandex-plus-dlya-alisy/` | Плюс для Алисы и Станции |
| `/yandex-muzyka/` | Яндекс Музыка: цена, сравнение со Spotify |
| `/yandex-plus-na-god/` | Плюс на год и длинные сроки |
| `/promokod-dlya-staryh-polzovateley/` | Сработает ли код на старом аккаунте |
| `/ceny/` | Официальные цены и история |
| `/kinopoisk/` | Кинопоиск в Казахстане |
| `/semeynaya-podpiska/` | Семья: как добавить близких |
| `/podbor/` | Квиз: промокод или приглашение |
| `/podarit-yandex-plus/` | Подарок и конструктор открытки |
| `/priglashenie-v-yandex-plus/` | Ссылки-приглашения, 20 стран |
| `/priglashenie-v-yandex-plus/kak-prinyat/` | Как принять приглашение |
| `/pomoshch/…` | Активация, отключение подписки |
| `/garantiya/`, `/kak-kupit/`, `/o-nas/`, `/kontakty/`, `/oferta/`, `/privacy/` | Доверие и документы |

Все страницы закрыты от индексации (`noindex`), пока в текстах есть плейсхолдеры в квадратных скобках и не подключён домен. Иллюстрации, фото и иконки сгенерированы через Codex, графики нарисованы кодом (SVG).
